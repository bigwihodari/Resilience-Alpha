Resilience Guard est une brique de sécurité réutilisable qui se pose devant votre application web et lui ajoute pare-feu applicatif, détection d'anomalies par IA, remédiation autonome, observabilité complète, haute disponibilité et un assistant d'exploitation — en une commande.

WAF OWASP (SQLi / XSS) Détection IA Isolation Forest Remédiation zéro-touch HA bascule automatique Assistant RAG local
Le constat

Sécuriser chaque application coûte cher et prend du temps

La plupart des applications métier n'embarquent ni pare-feu, ni détection d'attaque, ni supervision. Les rajouter demande de modifier le code, projet par projet.

Sans le module

L'application est exposée

Pas de filtrage des requêtes malveillantes, aucune visibilité sur le trafic, aucune réaction automatique en cas d'attaque, pas de secours en cas de panne. Chaque ajout de sécurité touche le code applicatif.

Avec Resilience Guard

Une passerelle protège tout

Le trafic passe par la passerelle du module : pare-feu, mesure, détection et remédiation sont transparents. On indique une seule variable — l'URL de l'app — et on lance l'overlay. Le code de l'application reste intact.

Architecture

Une passerelle devant, toute la défense derrière

La passerelle est le seul composant nouveau : WAF + proxy + métriques. Elle alimente une stack défensive autonome (détection, remédiation, observabilité, assistant) et un cockpit unique.

Ce que le module apporte

Sept capacités, zéro modification de code

🛡️

Pare-feu applicatif (WAF)

Signatures type OWASP (SQLi, XSS). Les requêtes malveillantes sont bloquées en 403 avant d'atteindre l'app.

📊

Observabilité & KPI

Débit, latence p95, taux 4xx/5xx, CPU/mémoire, requêtes bloquées — exportés vers Prometheus, Grafana, Loki.

🧠

Détection par IA

Isolation Forest + distance à la normale sur le trafic : score d'anomalie temps réel, sans seuils codés en dur.

⚙️

Remédiation autonome

Bouclier anti-DoS (load-shedding), transaction canari de vérification, timeline — zéro intervention humaine.

🔄

Haute disponibilité

Passerelle de secours + bascule et retour automatiques. Le service continue même si le nœud principal tombe.

🤖

Assistant IA (RAG)

Ollama + LangChain + FAISS en local : répond aux questions d'exploitation sur la base des procédures.

🖥️

Cockpit unifié

Un tableau de bord unique : santé des services, KPI live, détection, remédiation, HA, menaces et assistant.

📦

Réutilisable & isolé

Dossier autonome, overlay Docker Compose. S'installe devant une app dockerisée ou non, sans la toucher.

🎓

Pédagogique

Données et attaques fictives, usage labo. Démos fournies : site vitrine vierge et app de paiement minimale.

Installation

« Plug-and-protect » en une commande

On indique l'URL amont de l'application à protéger, puis on lance l'overlay. L'app est servie via la passerelle (port 8080), protégée et supervisée.

# À côté de votre application (dockerisée ou non)
PROTECTED_UPSTREAM=http://mon-app:8000 \
docker compose -f docker-compose.module.yml up -d --build

# Cockpit : http://localhost:8088   ·   Grafana : http://localhost:3000
# App protégée : http://localhost:8080
# Option haute disponibilité (2e passerelle + bascule auto)
docker compose -f docker-compose.module.yml -f docker-compose.ha.yml up -d --build
Scénario de démonstration

Du trafic normal à l'attaque, en direct

Trafic normal

On navigue sur l'app protégée : le cockpit affiche le débit, la latence p95 et l'état des services. Le détecteur apprend la « vie normale ».

Attaque applicative (injection SQL)

Une requête ?q=' OR 1=1-- est bloquée en 403 par le WAF ; le compteur de requêtes bloquées grimpe et l'orchestrateur confirme que l'application n'a jamais reçu l'attaque.

Montée en charge & remédiation

Un pic de trafic fait monter le score d'anomalie ; l'orchestrateur active le bouclier anti-DoS, vérifie par un canari, puis le lève automatiquement au retour à la normale.

Bascule haute dispo + assistant

On coupe la passerelle principale : le secours prend le relais (cockpit « bascule active »), puis retour auto. Une question à l'assistant RAG renvoie la procédure, sources citées.
